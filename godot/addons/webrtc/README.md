# WebRTC for the native (PC) builds

godotengine/webrtc-native 1.1.0-stable (https://github.com/godotengine/webrtc-native), only the 64-bit Windows and
Linux libraries. The voxel arena's co-op connects through it (scripts/voxel/net/voxel_rtc_transport.gd); the web
build has WebRTC built in and doesn't use this. Licences beside it. Added by the voxel session.
