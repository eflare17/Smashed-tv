# voxel_retro

The games room's consoles (Stage 7): a small libretro frontend as a GDExtension (`RetroCore`, `src/`), and the
libretro cores it plays, built from source (`src/build.sh`): Genesis Plus GX (Mega Drive, Master System, Game Gear;
free for non-commercial use only, see its LICENSE) and Snes9x (Super Nintendo; free for non-commercial use only).
No games are included: players add their own. The export puts the cores next to the exe (the `[dependencies]`).
Owned by the voxel session.
